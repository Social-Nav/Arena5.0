
修改以下两个文件。

## 1. 修正 map origin 处理

文件：

```text
task_generator/task_generator/manager/world_manager/world_manager_ros.py
```

在 `_map_callback()` 中，找到：

```python
if self._origin is not None:
    world_map.origin = self._origin
    self._origin = None
```

替换为：

```python
if self._origin is not None:
    world_map.origin = Position(
        x=self._origin.y,
        y=self._origin.x,
    )
    self._origin = None
```

## 2. 修正安全距离候选格尺寸

文件：

```text
task_generator/task_generator/manager/world_manager/world_manager.py
```

在 `_occupancy_to_available()` 中，找到：

```python
spread = scipy.signal.convolve2d(
    ...,
    mode="full",
    boundary="fill",
    fillvalue=int(WorldOccupancy.FULL)
)
```

仅将：

```python
mode="full",
```

替换为：

```python
mode="same",
```

## 3. 重建

在 Arena 容器内停止当前运行实例后执行：

```bash
cd /opt/arena_ws

rm -rf build/task_generator install/task_generator

export MAKEFLAGS=-j1
export CMAKE_BUILD_PARALLEL_LEVEL=1

colcon build --symlink-install --parallel-workers 1 \
  --base-paths src --build-base build --install-base install \
  --packages-select task_generator \
  --cmake-args -DPython3_ROOT_DIR=/opt/venv/bin/python3 -DBUILD_TESTING=OFF

source /opt/arena_ws/install/setup.bash
```
