# `HOST_SCENES_DIR` 配置说明

因为要将USD资产挂载到容器，需要修改工作区根目录 `.env` 里的 `HOST_SCENES_DIR`。

示例：

```env
HOST_SCENES_DIR=/InternUtopia/internutopia/assets/scenes/GRScenes-100

```

把它改成自己机器上的数据目录即可。

使用前需先重建 `arena_isaac` 镜像：`arena feature isaac update`

---

# 数据采集启动命令

```bash
ros2 launch arena_bringup arena.launch.py \
  sim:=isaac \
  robot:=Ai2_Bot2 \
  world:=hospital_1 \
  tm_robots:=scenario \
  save_data:=false
```

- `save_data:=true` 时开启数据记录，数据保存在工作区根目录下的 `collected_data/` 文件夹中。
  - 目录结构：`collected_data/<启动时间>/<episode_XXXXXX>/{data,rgb_videos,depth_videos}/`
  - 如果 `collected_data/` 不存在，启动时会自动创建。
  - 后处理（npy chunks → mp4，JSON → Parquet）：
    ```bash
    python3 src/Arena/arena_isaac/arena_isaac/arena_isaac/convert_json_to_parquet.py collected_data [--delete-src]
    ```
- `save_data:=false`（默认）时不记录数据，正常运行。

## IsaacSim 中观察 Head Camera 视角

在 IsaacSim 界面左上角的视口下拉菜单中，将 **Perspective** 切换为 **Camera**（对应挂载在 `head_link` 下的摄像头），即可实时预览机器人头部相机视角。
