# `HOST_SCENES_DIR` 配置说明

因为要将USD资产挂载到容器，需要修改工作区根目录 `.env` 里的 `HOST_SCENES_DIR`。

示例：

```env
HOST_SCENES_DIR=/InternUtopia/internutopia/assets/scenes/GRScenes-100

```

把它改成自己机器上的数据目录即可。

使用前需先重建 `arena_isaac` 镜像：`arena feature isaac update`

---
# 替换场景 USD

在使用 `grscenes` 场景时，先打开当前场景配置里的 `world.yaml`，找到 `path` 字段指向的 `start_result_navigation.usd` 文件路径，例如：

```yaml
path: /path/to/grscenes/start_result_navigation.usd
```

然后用文件夹中的 `start_result_navigation.usd` 去替换这个路径下原有的同名文件。

# 数据采集启动命令

> `world` 可选：`grscenes_1` … `grscenes_30`，以及 `airport` / `hospital_1` / `hospital_2` /
> `office_1` / `reception`。36 个场景均已配好 scenario（每个 6–12 个），完整列表见
> `arena_simulation_setup/worlds/`。

```bash
arena launch \
  sim:=isaac \
  robot:=Ai2_Bot2 \
  world:=grscenes_1 \
  tm_robots:=scenario \
  tm_obstacles:=scenario \
  save_data:=true \
  session_tag:=grscenes_1__default\
  social_yielding:=true
```

**常用启动参数：**

| 参数 | 默认值 | 说明 |
|------|--------|------|
| `sim` | — | 仿真后端，数据采集用 `isaac` |
| `robot` | `jackal` | 机器人型号，数据采集用 `Ai2_Bot2` |
| `world` | `map_empty` | 加载的场景（见上方可选列表） |
| `tm_robots` | `explore` | 机器人任务模式；场景采集用 `scenario`（读 scenario.yaml 里的起终点） |
| `tm_obstacles` | `random` | 障碍/行人生成模式；场景采集用 `scenario` |
| `save_data` | `false` | `true` 时开启数据记录 |
| `session_tag` | （空） | 数据子目录前缀，例如 `grscenes_1__default`，便于区分不同场景/场次 |
| `headless` | `0` | 取值 `-1`/`0`/`1`/`2`：`-1` 显示全部环境，`0` 全显示，`1` 仅 RViz，`2` 什么都不显示 |
| `social_yielding` | `auto` | 主动让行开关，三态 `auto`/`true`/`false`；`true` 时调用 LLM 选让行点（需配置 `API_KEY`） |
| `local_planner` | `social_mpc` | 局部规划器，见下方「Nav2 local planner 选择」 |



- `save_data:=true` 时开启数据记录。
  - 数据保存在 `src/Arena/collected_data/<session_tag>/`。
  - 目录结构：
    ```
    src/Arena/collected_data/
    └── <session_tag>/                 ← 由 session_tag 指定（未设置时用启动时间）
        └── <启动时间>/                ← session 目录（每次启动一个）
            └── episode_XXXXXX/
                ├── data/params.json       ← 每帧参数（位姿、摄像头参数等）
                ├── rgb_videos/chunk_XXXX.npy   ← 每 500 帧一个 chunk
                └── depth_videos/chunk_XXXX.npy
    ```
  - **导航失败（aborted / canceled）** 的 episode 会保留空文件夹作为标记，不写入任何数据。
  - 如果 `collected_data/` 不存在，启动时会自动创建。

- `save_data:=false`（默认）时不记录数据，正常运行。

## 后处理：npy chunks → mp4，JSON → Parquet

使用 `arena_isaac.data_logging.postprocess.raw_data_convert` 模块将采集的原始数据转换为可用格式（脚本已随 `arena_isaac` 包安装，用 `python3 -m` 调用，运行前需先 `source src/Arena/_meta/tools/source`）。

**参数说明：**

| 参数 | 说明 |
|------|------|
| `path` | 必填。可以是整个 `collected_data/` 目录（转换所有 session），也可以指定某个具体 session 目录 |
| `--delete-src` | 转换完成后删除源文件（`.npy` chunk 和 `params.json`），只保留转换结果 |
| `--fps N` | 输出视频帧率，默认 30 |

**用法示例：**

```bash
# 转换所有 session，保留源文件
python3 -m arena_isaac.data_logging.postprocess.raw_data_convert \
  src/Arena/collected_data

# 转换所有 session，转换后删除源文件
python3 -m arena_isaac.data_logging.postprocess.raw_data_convert \
  src/Arena/collected_data --delete-src

# 只转换某一次启动的数据，转换后删除源文件
python3 -m arena_isaac.data_logging.postprocess.raw_data_convert \
  src/Arena/collected_data/2026-04-29_09-35-01 --delete-src

# 指定视频帧率为 15fps
python3 -m arena_isaac.data_logging.postprocess.raw_data_convert \
  src/Arena/collected_data --fps 15
```

转换后每个 episode 目录结构：

```
episode_XXXXXX/
├── data/params.parquet        ← 原 params.json 转换而来
├── rgb_videos/rgb_video.mp4   ← 所有 rgb chunk 合并
└── depth_videos/depth_video.mp4
```

## 配置 API_KEY（instruction 生成 / 让行选点所需）

VLN 指令生成（`instruction_generator` / `batch_instructions`）和社交让行选点（`social_yielding_selector`）都通过 DMXAPI 网关调用视觉模型，需要一个 API key。

脚本统一从环境变量 `API_KEY` 读取，**不在源码里硬编码**：

```python
API_KEY = os.environ.get("API_KEY", "")
```

配置方式：在工作区根目录 `/opt/arena_ws/.env` 中写入（`source src/Arena/_meta/tools/source` 时会自动加载到环境）：

```env
API_KEY=sk-xxxxxxxxxxxxxxxx
```

> - `.env` 位于工作区根目录 `/opt/arena_ws/`，不在代码仓库（`src/Arena`）跟踪范围内；不要把 key 写进任何提交的文件。
> - 未设置时脚本会打印 `API_KEY not set` 并跳过模型调用。
> - 涉及的模型：指令生成用 `gemini-2.5-pro`，让行选点用 `gpt-5.4`（均经 DMXAPI 网关）。

## 生成 VLN 指令

对已转换出 `rgb_video.mp4` 的数据生成 R2R 格式导航指令。运行前需 `source src/Arena/_meta/tools/source` 并配置好 `API_KEY`。

**单个视频：**

```bash
python3 -m arena_isaac.data_logging.postprocess.instruction_generator \
  --video src/Arena/collected_data/grscenes_1__default/<session>/episode_XXXXXX/rgb_videos/rgb_video.mp4 \
  --tag grscenes_1__default
```

**批量处理一个场景目录**（遍历目录下所有 `rgb_video.mp4`，结果写入各自的 `instruction/instruction.json`）：

```bash
python3 -m arena_isaac.data_logging.postprocess.batch_instructions \
  --root src/Arena/collected_data/grscenes_1
```

## Nav2 local planner 选择

默认使用 **social_mpc**，可通过启动参数切换：

```bash
# Social MPC（默认）
arena launch ... local_planner:=social_mpc

# DWB
arena launch ... local_planner:=dwb

# Regulated Pure Pursuit
arena launch ... local_planner:=regulated_pure_pursuit
```

各 planner 配置文件位于 `src/Arena/arena_simulation_setup/configs/nav2/controllers/<planner_name>/controller_config.yaml`。

> 注意 `max_vel_x` / `max_speed_xy`（在 `arena_robots/.../model_params.yaml`）**只有 dwb 与
> regulated_pure_pursuit 读取**。social_mpc 的速度由
> `configs/nav2/profiles/<name>/profile.yaml` 的 `desired_linear_vel` 决定，详见
> [场景与社交配置说明.md](场景与社交配置说明.md)。
