# `HOST_SCENES_DIR` 配置说明

因为要将USD资产挂载到容器，需要修改工作区根目录 `.env` 里的 `HOST_SCENES_DIR`。

示例：

```env
HOST_SCENES_DIR=/InternUtopia/internutopia/assets/scenes/GRScenes-100

```

把它改成自己机器上的数据目录即可。

使用前需先重建 `arena_isaac` 镜像：`arena feature isaac update`

---

# 数据采集启动命令

```bash
ros2 launch arena_bringup arena.launch.py \
  sim:=isaac \
  robot:=Ai2_Bot2 \
  world:=hospital_1 \
  tm_robots:=scenario \
  save_data:=false
```

- `save_data:=true` 时开启数据记录。
  - 数据保存在 `src/Arena/collected_data/`（路径由代码自动定位 Arena 目录，无需手动配置）。
  - 目录结构：
    ```
    src/Arena/collected_data/
    └── <启动时间>/                    ← session 目录（每次启动一个）
        └── episode_XXXXXX/
            ├── data/params.json       ← 每帧参数（位姿、摄像头参数等）
            ├── rgb_videos/chunk_XXXX.npy   ← 每 500 帧一个 chunk
            └── depth_videos/chunk_XXXX.npy
    ```
  - **导航失败（aborted / canceled）** 的 episode 会保留空文件夹作为标记，不写入任何数据。
  - 如果 `collected_data/` 不存在，启动时会自动创建。

- `save_data:=false`（默认）时不记录数据，正常运行。

## 后处理：npy chunks → mp4，JSON → Parquet

使用 `raw_data_convert.py` 脚本将采集的原始数据转换为可用格式。

**参数说明：**

| 参数 | 说明 |
|------|------|
| `path` | 必填。可以是整个 `collected_data/` 目录（转换所有 session），也可以指定某个具体 session 目录 |
| `--delete-src` | 转换完成后删除源文件（`.npy` chunk 和 `params.json`），只保留转换结果 |
| `--fps N` | 输出视频帧率，默认 30 |

**用法示例：**

```bash
# 转换所有 session，保留源文件
python3 src/Arena/arena_isaac/arena_isaac/arena_isaac/raw_data_convert.py \
  src/Arena/collected_data

# 转换所有 session，转换后删除源文件
python3 src/Arena/arena_isaac/arena_isaac/arena_isaac/raw_data_convert.py \
  src/Arena/collected_data --delete-src

# 只转换某一次启动的数据，转换后删除源文件
python3 src/Arena/arena_isaac/arena_isaac/arena_isaac/raw_data_convert.py \
  src/Arena/collected_data/2026-04-29_09-35-01 --delete-src

# 指定视频帧率为 15fps
python3 src/Arena/arena_isaac/arena_isaac/arena_isaac/raw_data_convert.py \
  src/Arena/collected_data --fps 15
```

转换后每个 episode 目录结构：

```
episode_XXXXXX/
├── data/params.parquet        ← 原 params.json 转换而来
├── rgb_videos/rgb_video.mp4   ← 所有 rgb chunk 合并
└── depth_videos/depth_video.mp4
```

## Nav2 local planner 选择

默认使用 **DWB**，可通过启动参数切换：

```bash
# DWB（默认，采样评分型）
ros2 launch arena_bringup arena.launch.py ... local_planner:=dwb

# Regulated Pure Pursuit（大角度转弯时先原地旋转再前进）
ros2 launch arena_bringup arena.launch.py ... local_planner:=regulated_pure_pursuit
```

各 planner 配置文件位于 `src/Arena/arena_simulation_setup/configs/nav2/controllers/<planner_name>/controller_config.yaml`。
